G41 relógio GPS 4G e pingente SOS 2 em 1

Dispositivo GPS de segurança para idosos - uso como relógio ou pingente SOS

G41 é um dispositivo de segurança GPS 4G vestível para idosos que pode ser usado como smartwatch ou como pingente SOS. Suporta chamada de emergência, alerta de queda, comunicação bidirecional, recursos de localização e gestão remota para projetos de cuidado.

Design vestível 2 em 1

O mesmo dispositivo G41 pode ser usado no pulso com pulseira de silicone ou como pingente SOS, ajudando a adaptar o uso às necessidades de cada idoso.

Plataforma e integração

G41 funciona com Globe GPS Tracker e uma plataforma de gestão PC unificada. Os dados do dispositivo podem ser enviados para uma plataforma designada ou outra plataforma de negócios especificada, com integração API cloud-to-cloud para projetos B2B adequados.
