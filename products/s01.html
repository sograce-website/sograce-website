Emergency SOS Intercom

S01 4G GPS Emergency SOS Alarm

4G Smart Intercom for Elderly Care and Home Safety

S01 is a 4G GPS emergency SOS alarm and smart intercom designed for elderly care, nursing homes, home care, community care stations, aging-friendly renovation, smart security and smart home projects.

Request QuoteOEM/ODM Project

Main Functions

  • 4G voice communication
  • GPS emergency SOS alarm
  • Two-way intercom
  • Host SOS button
  • Handle SOS button
  • Up to 5 dial phone numbers
  • Up to 5 SMS numbers
  • Incoming-call whitelist
  • Automatic answering
  • Alarm address
  • Alarm map location
  • IoT management platform alarm push
  • Wireless accessory pairing by QR code
  • Supports additional wireless detectors and accessories
  • Low signal warning
  • Low battery warning
  • External power failure and recovery alarm
  • Remote firmware upgrade
  • Cloud text broadcasting
  • Voice prompts for different detector alarm types

Wireless Accessories

  • Wireless emergency button
  • Door/window sensor
  • PIR motion detector
  • Smoke detector
  • Gas detector
  • Water leakage detector
  • Remote control

Application Scenarios

  • Elderly care
  • Nursing homes
  • Home-based elderly care
  • Community elderly care
  • Aging-friendly renovation
  • Smart security
  • Smart home
  • Assisted living projects
