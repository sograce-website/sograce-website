G41 reloj GPS 4G y colgante SOS 2 en 1

Dispositivo GPS de seguridad para mayores - uso como reloj o colgante SOS

G41 es un dispositivo de seguridad GPS 4G portátil para adultos mayores que puede usarse como reloj inteligente o como colgante SOS. Soporta llamadas de emergencia, alerta de caída, comunicación bidireccional, funciones de localización y gestión remota para proyectos de cuidado.

Plataforma e integración

G41 funciona con Globe GPS Tracker y una plataforma de gestión PC unificada. Los datos del dispositivo pueden subirse a una plataforma designada u otra plataforma empresarial especificada, con integración API cloud-to-cloud para proyectos B2B adecuados.
